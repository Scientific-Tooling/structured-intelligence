# Research Workflow

1. Frame question and scope.
2. Gather primary sources.
3. Evaluate quality and conflicts.
4. Synthesize findings with citations.
5. Record open questions and confidence level.

Start with the [guided PDF-to-brief workflow](quickstart.md), or ask an agent to
use the bundled `paper-to-brief` skill. The CLI manages the workspace and reader
on Windows, Linux and macOS. For the individual tool commands, see the
[Windows/PowerShell walkthrough](windows-quickstart.md) or
[Linux/macOS walkthrough](unix-quickstart.md).
For a paper already stored in RKS, use the [source-reading workflow](source-reading.md)
to open a verified PDF revision in Agent PDF Workbench. Then [import selected
evidence](evidence-import.md) and [generate a passage-linked brief](source-linked-brief.md).
