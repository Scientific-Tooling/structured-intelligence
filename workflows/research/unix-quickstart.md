# RKS + PDF Workbench: Linux/macOS walkthrough

Follow the concise [Linux/macOS walkthrough](https://scientifictooling.org/guides/rks-apw-linux-macos/)
for Bash or zsh: install compatible source checkouts, ingest a local PDF, highlight
a passage, preview/apply selected evidence, and generate a source-linked brief.

The [Markdown source](https://github.com/Scientific-Tooling/Scientific-Tooling.github.io/blob/main/guides/rks-apw-linux-macos.md)
is maintained with its generated page in the organization website repository.
It includes Python/venv prerequisites, actual-ID selection, replay and backup
guidance. No API key, MCP setup, Node.js or jq is required for this path.

See also the [Windows walkthrough](windows-quickstart.md),
[source-reading contract](source-reading.md), [selected evidence import](evidence-import.md),
and [passage-linked briefs](source-linked-brief.md).
