# RKS + PDF Workbench: Windows walkthrough

Follow the concise [Windows/PowerShell walkthrough](https://scientifictooling.org/guides/rks-apw-windows/)
to install compatible source checkouts, ingest one local PDF, highlight a passage,
preview and apply its selected evidence import, and generate a source-linked brief.

The [Markdown source](https://github.com/Scientific-Tooling/Scientific-Tooling.github.io/blob/main/guides/rks-apw-windows.md)
is maintained with its generated web page in the organization website repository.
It includes the required source revisions, actual-ID selection, replay checks,
backup guidance and common failures. No API key or MCP setup is required for this path.

Detailed contracts: [source reading](source-reading.md),
[selected evidence import](evidence-import.md), and [passage-linked briefs](source-linked-brief.md).
