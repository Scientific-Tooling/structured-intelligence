# Discovery walkthrough screenshots

2026. See the [step-by-step guide](../../discovery-screenshots.md) for instructions.

or article text was fabricated or composited into the screenshots.

and variance stabilization of single-cell RNA-seq data using regularized negative

Screenshots 08–09 show portions of Vieth et al. (2019), *A systematic evaluation
of single cell RNA-seq analysis pipelines*,
[DOI](https://doi.org/10.1038/s41467-019-12266-7).
